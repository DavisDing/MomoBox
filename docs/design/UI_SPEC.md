# 「嬷嬷的小箱子」前端 UI 设计与多主题规范说明书

## 1. 概述与设计原则

本规范严格依据产品需求文档（PRD V3.0）与架构设计（DESIGN.md）制定，明确了 **手机端（Mobile App）** 与 **后端管理端（NAS Web Admin）** 的页面设计、交互状态规范、组件体系及三大核心主题体系。

### 1.1 核心原则
- **实用清晰**：信息层级紧凑，到期状态（正常、临期、过期）一眼识别，降低家务管理认知负担。
- **本地优先 & 渐进增强**：单机模式独立完整；NAS 模式提供家庭共享、多设备同步与系统级状态监控。
- **主题深度适配（皮肤化 + 语境化）**：主题不仅包含色彩、圆角、阴影等视觉皮肤，还囊括吉祥物、文案体系（古风内务府/未来四次元/中性现代）、空状态插画与推送通知文案。
- **完整状态覆盖**：所有页面均提供 Normal、Loading、Empty、Error、Success、Disabled 6大完备状态。

## 3. 手机端 UI 页面设计架构

App 移动端采用 **“4 个核心业务入口 + 中央突出 AI 助手”** 的主导航体系，顶层与全局模态承载录入、详情与管理操作：

```text
首页 (Home)  |  库存 (Inventory)  |  [ AI 助手 ]  |  家居 (Smart Home)  |  我的 (Settings)
```

### 3.1 页面 1：家庭总览首页（Tab 1 - Home）
- **顶部 Header**：
  - 左侧：当前家庭名称、连接状态指示（单机 / NAS 同步状态、HA 在线/离线指示小圆点）。
  - 中间/右侧：动态主题问候语、NAS 快速触发同步按钮。
- **待处理提醒摘要卡片（原“提醒”页面合并至此）**：
  - 统计胶囊条：已过期 X 件、3天内即将到期 Y 件、开封后临期 Z 件、库存偏低告急 W 件。
  - 交互行为：点击具体某项胶囊，直接进入带该类型预过滤的“待处理详情页面（Alerts Detail）”；提供“查看全部”入口。
- **采买速览卡片（原“采买清单”页面合并至此）**：
  - 展示待买条目数量、低库存自动触发补货项与 AI 建议补货项。
  - 点击卡片跳转进入二级完整采买页（保留二级路由 `/shopping`），支持勾选已买并直接唤起入库表单。
- **家居快捷场景操作条**：
  - 常用场景快捷按钮：观影模式、出门采买、回家、夜间整理（点击调用 HA 场景/脚本，附带状态反馈 Toast）。
- **快捷动作入口**：
  - 扫码/AI 拍照/手动入库快捷浮标。

### 3.2 页面 2：库存物资管理（Tab 2 - Inventory）
- **搜索栏**：支持商品名、拼音、品牌、存放位置、条码搜索；主题适配文案（如嬷嬷主题："搜寻箱中宝物..."）。
- **分类与状态筛选器**：
  - 分类横向 Pill 胶囊滚动条（全部、药品、食品、日化、美妆、母婴、生鲜等）。
  - 状态快捷过滤：全部 / 临期 / 已过期 / 缺货告急。
- **库存多批次卡片流**：
  - 卡片信息：物品封面（支持手绘分类占位）、商品名称、规格、总库存量、存放位置。
  - 效期徽标：根据最先到期批次自动高亮（绿色安全 / 黄色临期 / 红色过期倒计时）。
  - 快捷手势/操作条：快速 FEFO 消耗 (-1)、补充 (+1)、移入采买单。
- **浮动操作**：右下角可拖拽扫码/添加物资悬浮按钮。

### 3.3 中央主入口：AI 家庭助手（Tab 3 - Central AI Assistant）
- **导航栏形态**：
  - 底部导航栏正中央突出的圆形交互按钮，融入当前主题吉祥物（嬷嬷/哆啦A梦/经典小箱子），带呼吸感与点击轻动效。
- **AI 交互抽屉/面板**：
  - 支持自然语言文字/语音输入，分为三大意图处理：
    1. **设备控制**：“打开电视”、“空调调到 26 度制冷”、“开启制冰机” -> 识别目标设备，调用 Home Assistant 并展示执行回执卡片。
    2. **物资管理**：“家里还有多少洗衣液？”、“把抽纸加入采买单” -> 查询或修改本地/NAS 库存与采购清单。
    3. **混合联动任务**：“我要洗衣服” -> 识别洗衣机状态，弹出耗材选择卡片（洗衣液 1 份 / 洗衣凝珠 1 颗），用户确认后执行操作。
  - 若目标设备不明确（如多台电视），主动追问用户，不盲目执行。

### 3.4 页面 4：智能家居（Tab 4 - Smart Home）
- **顶部状态栏**：
  - Home Assistant 服务状态（已连接 / 离线 / 局域网重试中）、已授权设备数。
- **常用场景与自动化**：
  - 观影模式、回家模式、离家模式、夜间模式、厨房整理、采购出门（点击直接触发对应 HA 场景/脚本并显示回执）。
- **房间与设备控制列表（按区域分组，支持卡片式开关与属性调节）**：
  - **客厅**：电视（开关）、主灯（开关/调光）、空调（开关/模式/设定温度）。
  - **厨房**：制冰机（开关/运行状态）、厨房照明、净水器（滤芯寿命提醒）。
  - **阳台**：洗衣机（运行状态：空闲 / 洗涤中 / 已完成）。
- **设备耗材联动看板**：
  - 展示联动事件与日志：如“阳台洗衣机完成洗涤 -> 建议扣减洗衣液 1 份（待确认）”；支持用户点击“确认扣减”或“忽略”。
- **空状态与异常态**：
  - 未配置 HA 时，展示引导配置卡片（跳转“我的 -> Home Assistant 设置”）；HA 离线时明确提示“HA 暂时离线，库存与采买不受影响”。

### 3.5 页面 5：我的与设置（Tab 5 - Profile & Settings）
- **家庭与协同**：家庭组管理、成员列表与权限分配、NAS 增量同步状态。
- **智能集成**：
  - **Home Assistant 配置**：局域网地址（如 `http://192.168.1.x:8123`）、Long-Lived Access Token 配置与测试连接、设备/场景白名单选择。
  - **设备耗材联动规则**：配置洗衣机默认耗材配方（标准洗/大件洗扣减洗衣液或凝珠、每次询问/自动扣减）。
- **主题换肤中心**：默认主题、嬷嬷主题、哆啦A梦主题、深夜模式实时切换与预览。
- **AI 服务配置**：API Key 安全录入（OpenAI / DeepSeek / 本地 Ollama）、模型选择、代币使用审计。
- **数据与安全**：全量 JSON 备份导出 / 导入恢复。

---

### 3.6 核心二级页面与模态流程
- **待处理提醒详情页（Alerts Detail）**：由首页提醒摘要跳转，支持按类型过滤、单条标记已处理、批量处理、移入采买单。
- **采买清单详情页（Shopping List）**：由首页采买卡片跳转，支持待买/已购列表、勾选已买唤起入库草稿。
- **商品详情与多批次管理（Product Detail）**：批次时间线、开封打卡、FEFO 消耗/补充/报废、说明书与问答。
- **扫码 / AI 拍照入库流程（Intake Flow）**：条码取景、包装拍照、本地 OCR 识别、AI 提取草稿确认后入库。

## 4. 后端管理端（NAS Web Admin）UI 设计

面向绿联 DX4600 等私有部署场景的 Web 响应式管理后台，提供桌面端高密度的家庭协同与监控体验：

1. **总览仪表盘（Dashboard）**：家庭整体物资总览、效期分布漏斗图、耗尽预警、NAS 容器资源（CPU/内存/Ollama 运行状态）。
2. **多家庭与成员权限管理（Family & Members）**：家庭组创建、邀请码生成、角色管理（管理员/普通成员/只读观察员）。
3. **全量库存与历史批次台账（Inventory Ledger）**：支持高密度表格视图、多维高级过滤、批量导入/导出 Excel、条码库维护。
4. **消耗分析与 AI 预测报表（Analytics & AI Insights）**：按月/季度物品消耗趋势图表、采购成本统计、日均消耗速率与预测补货看板。
5. **系统监控与 AI / 接口配置（System & AI Settings）**：PostgreSQL 状态、数据同步冲突日志审计、Ollama 代理与云端模型 Key 管理。

## 5. UI 状态规范（State System）

所有前端模块均需遵循以下状态体系规范：
1. **Normal（正常态）**：图文规范，卡片层次分明，微动效反馈。
2. **Loading（加载态）**：骨架屏（Skeleton）或主题定制 Loading（如嬷嬷主题的“嬷嬷正在翻箱倒柜...”沙漏动效）。
3. **Empty（空数据态）**：主题定制插画 + 个性化文案 + 明确的 Primary 行动按钮（CTA）。
4. **Error（异常态）**：网络脱机 / 识别失败 / 后端无响应，展示明确错误原因与“重试”或“降级手动”按钮。
5. **Success（成功态）**：录入成功 / 消耗成功，轻量 Toast 或顶部 Banner 快速淡出，不阻断连续录入操作。
6. **Disabled（禁用态）**：表单字段置灰、按钮透明度 40%、鼠标禁用手势并带有原因 Tooltip。
