# 「嬷嬷的小箱子」前端 UI 设计与多主题规范说明书

## 1. 概述与设计原则

本规范严格依据产品需求文档（PRD V3.0）与架构设计（DESIGN.md）制定，明确了 **手机端（Mobile App）** 与 **后端管理端（NAS Web Admin）** 的页面设计、交互状态规范、组件体系及三大核心主题体系。

### 1.1 核心原则
- **实用清晰**：信息层级紧凑，到期状态（正常、临期、过期）一眼识别，降低家务管理认知负担。
- **本地优先 & 渐进增强**：单机模式独立完整；NAS 模式提供家庭共享、多设备同步与系统级状态监控。
- **主题深度适配（皮肤化 + 语境化）**：主题不仅包含色彩、圆角、阴影等视觉皮肤，还囊括吉祥物、文案体系（古风内务府/未来四次元/中性现代）、空状态插画与推送通知文案。
- **完整状态覆盖**：所有页面均提供 Normal、Loading、Empty、Error、Success、Disabled 6大完备状态。

## 3. 手机端 UI 页面设计架构

App 底部导航包含 4 个 Tab，顶层与全局模态承载录入、详情与管理操作：

### 3.1 页面 1：库存首页（Tab 1 - Inventory）
- **顶部 Header**：
  - 左侧：当前家庭组/单机状态指示器（带网络同步小圆点）。
  - 中间/右侧：动态主题问候语、NAS 同步触发按钮、扫码入库快捷浮标。
  - 搜索栏：支持商品名、拼音、品牌、存放位置、标签搜索；主题适配文案（如嬷嬷主题："搜寻箱中宝物..."）。
- **分类与状态筛选器**：
  - 分类横向 Pill 胶囊滚动条（全部、药品、食品、日化、美妆、母婴、生鲜等）。
  - 状态快捷过滤：全部 / 临期 (30天内) / 已过期 / 缺货告急。
- **库存多批次卡片流**：
  - 卡片信息：物品封面（支持默认分类手绘占位）、商品名称、规格、当前总库存、存放位置（如“主卧药箱”、“冰箱冷藏”）。
  - 效期徽标：根据最先到期批次自动高亮（绿色安全/黄色临期/红色过期倒计时）。
  - 批次摘要：若多批次，显示“共 3 个批次，最近 2026-10-15 到期”。
  - 快捷手势：向左滑动呼出快速消耗 (-1)、补充 (+1)、移入采买清单。

### 3.2 页面 2：采买清单（Tab 2 - Shopping List）
- **待买列表与已完成归档**：
  - 支持一键勾选已买并直接唤起“入库”弹窗。
  - 支持“AI 智能补货建议”悬浮条（分析近 30/60 天消耗速度，预警自动入单）。
  - 手动添加采购项（名称、期望数量、期望规格、建议品牌）。

### 3.3 页面 3：效期提醒看板（Tab 3 - Alerts）
- **主题吉祥物看板卡片**：
  - 嬷嬷或哆啦A梦吉祥物形象根据紧急情况变换表情（如焦急催促、安逸点赞）。
  - 汇总统计条：已过期 X 件、3天内过期 Y 件、开封后临期 Z 件、库存告急 W 件。
- **分组列表**：
  - 按紧急程度降序排列（红色已过期置顶并附带处理建议，如“报废销毁/堆肥”）。
  - 支持批量标记已处理、一键移入采买单。

### 3.4 页面 4：商品详情与多批次管理（Detail & Batches）
- **商品主信息区**：
  - 商品名、品牌、条码、分类、存放位置、说明书绑定状态、开封后保质期规则。
- **多批次列表（核心交互）**：
  - 批次卡：批次号/生产日期、保质期至、开封状态（未开封 / 已开封于 2026-08-20）、剩余数量、初始数量。
  - 批次操作条：消耗 1 件、开封打卡、查看独立条码、报废。
- **说明书与 AI 问答抽屉**：
  - 说明书 OCR 识别文本、快速搜索禁忌与用法、一键呼出 AI 问答（“孕妇能吃吗？”、“每次吃几粒？”）。

### 3.5 页面 5：扫码 / AI拍照入库流程（Add & Scan Flow）
- **取景器界面**：
  - 顶部切换：条码扫码 / 生产日期与保质期 OCR 拍照 / 商品正面识别。
  - 底部功能：手电筒、相册选图、切换手动录入。
- **AI 识别确认与历史带入表单**：
  - 自动识别条码并拉取历史同款数据（若历史录入过，自动回填保质期天数、分类、存放位置）。
  - 日期解析卡：生产日期 + 保质期（天/月）或直接识别到期日，提供置信度提示与一键纠错。

### 3.6 页面 6：我的与设置（Tab 4 - Profile & Settings）
- **主题切换中心（含实时换肤预览）**：
  - 默认主题、嬷嬷主题、哆啦A梦主题、深夜模式一键无缝热切换。
  - AI 自定义主题生成器入口。
- **网络与 NAS 状态配置**：
  - 单机 / NAS 双模式切换、NAS 地址（`http://192.168.x.x:8080`）、登录凭证、家庭组切换。
- **API 设置 & 数据备份**：
  - 云端 LLM Key（OpenAI / DeepSeek）或本地 Ollama 连接测试。
  - JSON 备份导出 / 恢复。

## 4. 后端管理端（NAS Web Admin）UI 设计

面向绿联 DX4600 等私有部署场景的 Web 响应式管理后台，提供桌面端高密度的家庭协同与监控体验：

1. **总览仪表盘（Dashboard）**：家庭整体物资总览、效期分布漏斗图、耗尽预警、NAS 容器资源（CPU/内存/Ollama 运行状态）。
2. **多家庭与成员权限管理（Family & Members）**：家庭组创建、邀请码生成、角色管理（管理员/普通成员/只读观察员）。
3. **全量库存与历史批次台账（Inventory Ledger）**：支持高密度表格视图、多维高级过滤、批量导入/导出 Excel、条码库维护。
4. **消耗分析与 AI 预测报表（Analytics & AI Insights）**：按月/季度物品消耗趋势图表、采购成本统计、日均消耗速率与预测补货看板。
5. **系统监控与 AI / 接口配置（System & AI Settings）**：PostgreSQL 状态、数据同步冲突日志审计、Ollama 代理与云端模型 Key 管理。

## 5. UI 状态规范（State System）

所有前端模块均需遵循以下状态体系规范：
1. **Normal（正常态）**：图文规范，卡片层次分明，微动效反馈。
2. **Loading（加载态）**：骨架屏（Skeleton）或主题定制 Loading（如嬷嬷主题的“嬷嬷正在翻箱倒柜...”沙漏动效）。
3. **Empty（空数据态）**：主题定制插画 + 个性化文案 + 明确的 Primary 行动按钮（CTA）。
4. **Error（异常态）**：网络脱机 / 识别失败 / 后端无响应，展示明确错误原因与“重试”或“降级手动”按钮。
5. **Success（成功态）**：录入成功 / 消耗成功，轻量 Toast 或顶部 Banner 快速淡出，不阻断连续录入操作。
6. **Disabled（禁用态）**：表单字段置灰、按钮透明度 40%、鼠标禁用手势并带有原因 Tooltip。
