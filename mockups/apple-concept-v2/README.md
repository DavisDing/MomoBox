## 导航与默认首页

底栏从左到右固定为「助手 / 物品 / 今日 / 家居 / 设置」。今日为第三项，并用实色选中态强调首页。窄屏预览默认展示今日；宽屏三画框展示助手、今日、家居，每个画框均可独立切换全部五页。

- 助手：独立全页，包含快捷提问、输入区、对话展示、新建对话及右上角 AI 服务入口。
- 物品：延续 V1 搜索、分类、实物缩略图和详情。
- 今日：首页；保留临期提醒、记录新物品、采买清单入口。
- 家居：房间筛选、场景入口和设备状态。
- 设置：明确列出 AI 服务、家居连接、家庭同步与日常偏好。
- 采买：作为今日内的子流程，底栏仍将今日标记为当前一级入口。

AI 服务配置可从助手右上角和设置页进入，展示服务名、地址、模型和密钥字段；输入仅用于界面演示，不发起网络连接，不存储密钥。演示名称在当前画框的会话内显示。助手回复为明确标注的预设演示文本，设备开关仅改变演示状态，场景不会实际执行。

## 家居环境概览：紧凑版

用户要求在家居页展示室内温度、室内湿度、室外温度和体感，并进一步要求减少顶部占位。本轮将环境区重排为约128px高的双栏摘要：左侧室内温度与湿度，右侧室外温度与体感；小字保留来源、更新时间与演示标记，详细规则通过“数据来源”打开。五入口、其他页面与真实业务代码保持本轮既定范围。

`home-environment.html` 同时对照三种演示状态：有室内传感器与家庭天气、公共天气回退、暂无数据。新导出的当前截图为 `environment-light.jpg` 和 `environment-dark.jpg`；上面的 `preview-*.jpg` 保留为环境区加入前的 V2 记录。

数据规则为设计提案，尚未接通真实来源：

- 室内温湿度只读用户授权的对应房间传感器。没有传感器时显示“—”，不将公共室外天气或空调设定温度当作室温。
- 室外天气优先使用可用且新鲜的家庭天气实体或室外传感器；缺失字段可由用户所选城市的公共天气补齐，逐字段标注来源，不混用更新时间。公共天气服务商、超时/缓存和授权交互在功能实现前确认。
- 体感在本版明确属于室外天气。没有可靠来源就留空；未新增室内体感估算公式。
- 传感器过期、天气失败、无位置等生产状态需要在实际接入时落实。本版只演示有数据、公共回退和无数据，不声称实现了真实自动回退。

检查：三种状态在当前324px内容宽度下环境卡片均测得128px；来源弹层可进入并切换预览状态；公共回退保持室内温湿度为空；卧室筛选显示22.8°/52%的卧室演示数据；无浏览器控制台错误；JS语法和差异空白检查通过。真实接口、原生Flutter、窄视口与系统辅助能力仍未执行。
