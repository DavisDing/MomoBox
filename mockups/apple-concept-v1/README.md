# MomoBox 移动端概念 V1：日常，有序

2026-11-09，依据用户本轮授权重新探索移动端 UI，先交付可评审的渲染与交互原型。

暖白、深墨文字、鼠尾草绿；系统字体、大标题、轻分组和少量实物包装插画。材质集中于浮动底栏，内容表面保持清晰。导航提案为「今日 / 物品 / 采买 / 我的」，助手按需唤起。旧导航和页面结构不是本轮原型的限制；该提案尚未作为 Flutter 产品需求落地。

## 查看

直接用浏览器打开 `index.html`。不需安装依赖或连接后端。可选本机预览：

```sh
python3 -m http.server 8764 --bind 127.0.0.1 --directory mockups/apple-concept-v1
```

- `preview-light.jpg`：今日、物品、采买三屏实际浏览器渲染。
- `preview-dark.jpg`：同一套页面的深色模式。
- `preview-detail.jpg`：物品详情弹层。
- `index.html`、`style.css`、`app.js`：可编辑原型。
- `icons.js`：从工作区已有工具包复制的 Lucide 1.8.0，ISC 许可见 `ICONS-LICENSE`；不新增应用依赖，不需要远程 CDN。

## 可体验范围

底部导航、分类筛选、名称/位置搜索、排序、物品详情、演示消耗及撤销、加入采买、采买勾选及撤销、手动添加采买、深浅色切换。详情弹层使用可重新定向的弹簧；拖动跟随手指、释放速度参与落点；有减少动态、减少透明度和高对比度的样式回退。

所有数字和物品均为独立演示数据。每个手机画框拥有独立状态，刷新清空。48 种物品/6 个位置属于概念首屏文案，缩略数据集仅展示 6 个物品。新物品表单仅演示填写和完成反馈；模型、家庭共享、具体设置与实际入库流程未接通，不代表现有功能已完成。
